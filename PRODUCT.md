# Feenland Mathezauber

A touch-first math adventure for children, with responsive phone, tablet and desktop layouts. The user-approved reference is a fairyland with a red-haired fairy, green leaf dress, cream surfaces, dark blue text and pink primary actions. Keep artwork simple in the first delivery.

The Home screen offers Continue/Start, Explore Worlds, cumulative achievements and a Settings gear. Launch languages are en/de/es/fr; language selection lives in Settings. Content follows World → Chapter → Level → Challenge with stable IDs. Progress stays locally and earned accomplishments survive catalog growth. All old unicorn, berry and number-bridge content is removed by explicit user request.

Current delivery: Home, World Map, World Detail chapter paths, Chapter Detail level selection, challenge previews, result-driven completion, and language settings. Placeholder completions are clearly labeled demos and saved separately from real learning mastery and chapter awards. Actual mathematical gameplay remains deferred. No fake learning achievements, timer, accounts, analytics or cloud sync.


Math practice: Mystery Castle now includes “Your path to 30”, nine directly selectable stages covering tens and ones, missing-addend addition, crossing tens, missing-subtrahend subtraction, missing starting numbers, and mixed practice. Each stage shows its number range and example. Eight-question rounds use independent, locally remembered difficulty and pace preferences. Relaxed pace has no timer; steady/quick offer 45/20 seconds per question with pause and no answer lockout at expiry. Completing all questions records a real practice result; existing preview adventures retain separate demo behavior. No tower-defense engine exists in this checkout.
