# Feenland Mathezauber design

The supplied fairyland mockup is visual authority. One simple reusable illustration establishes a red-haired fairy in a green leaf dress with translucent wings and a star wand. Future artwork must preserve those traits.

Tokens live in `src/styles.css`: ink #172555, background #edf7fb, cream #fffdf5, primary pink #c91860, secondary text #4c6079. Local Fredoka 400/600. Minimum 44px targets, visible blue focus rings, text labels for states, reduced-motion support. Pink is reserved for the primary next action.

Phone Home stacks copy, art, actions and achievements. Tablets place copy/art side by side with actions across the width. Desktop uses a wide hero with actions below the copy and a horizontal achievement panel. No fixed viewport heights. Dialogs use native modal semantics with Escape dismissal and restored focus. No hover-only actions.
